# Data

`../data_tickets.parquet` is the source, the customer support tickets dataset
from Hugging Face (Tobi-Bueck/customer-support-tickets), 61,765 rows in
English and German. `../splits/` holds the deduplicated 80/20 split that
`src/common.py` writes with seed 42. Both are in git so every result is
reproducible from a fresh clone.

Everything else under `data/` is derived and not in git. Large files are
regenerated by the scripts that made them.

| Directory | What | Made by |
| --- | --- | --- |
| `synthetic/split.json` | the core (85%) and validation (15%) indices into the training set, the protocol every decision used | in git |
| `synthetic/*_summary.json`, `error_report.json`, `val_predictions.json` | what each generation run produced and where the network missed | in git |
| `synthetic/*.jsonl` | the generated tickets themselves | `src/experiments/synthetic_data/` |
| `x_german/` | the translated German tickets and their embeddings, needed by the final router | `src/final/translate.py`, `src/final/embed.py` |
| `x_semantic/` | cached embeddings for the English-only router and its track | `src/final/router_english_only.py` |
| `x_lexical/`, `x_classifier/`, `x_unfamiliar/` | caches of the other research tracks | `src/experiments/retrieval_tracks/` |
| `lora*/` | prompt and completion files for the LoRA fine-tunes | `src/experiments/` |

Nothing under `data/` was made from the test set. The German translations are
filtered against evaluation tickets at fit time, inside `src/final/router.py`,
not here.
